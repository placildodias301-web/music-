# Wilsify AI — Frontend

Vite + React + TypeScript + Tailwind CSS. Setup, environment variables, running and testing for the whole project (frontend and backend) are in the root [`INSTALLATION.md`](../INSTALLATION.md); project overview in [`../README.md`](../README.md).

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # outputs to dist/
```

Set `VITE_API_URL`, `VITE_SUPABASE_URL` and `VITE_SUPABASE_PUBLISHABLE_KEY` (see `.env.example` and `INSTALLATION.md` §3).
