# Wilsify AI — Frontend

Vite + React + TypeScript + Tailwind CSS. See the root [`../README.md`](../README.md) for setup, running, and the full picture (including the backend).

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # outputs to dist/
```

Set `VITE_API_URL` (see `.env.example`) to point at the backend.
